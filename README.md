# loreforge-world

O contêiner dos mundos jogáveis do Loreforge. A ideia do jogo é ter N mundos —
cada um vive no seu próprio repositório, montado aqui como submódulo.

## Mundos

- [`tardenia/`](https://github.com/rcorbellini/tardenia) — As Brumas de Tardênia,
  o mundo em jogo hoje (Costa de Ferro é uma região dela).

Novos mundos entram como novos submódulos, ao lado de `tardenia/`.
